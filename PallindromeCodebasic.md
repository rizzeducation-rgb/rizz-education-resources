# rizz-education-resources

Small, free tools and resources by Rizz Education Advisors.

## Palindrome Checker

`palindrome.py` checks whether a word or sentence reads the same forwards and backwards. It ignores spaces, punctuation and capital letters.

### Run it

    python palindrome.py

### Example

    "madam" -> palindrome
    "A man, a plan, a canal: Panama" -> palindrome
    "hello" -> not a palindrome
